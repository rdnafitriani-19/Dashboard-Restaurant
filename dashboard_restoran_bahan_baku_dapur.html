Panduan Spesifikasi & Penjelasan Logika (README)

1. Entitas Bahan Baku Dapur

Setiap data bahan baku disimpan dengan struktur objek berikut:

{ id: "BB-001", nama_bahan: "Daging Sapi Tenderloin", kategori: "Daging & Unggas", stok: 15, satuan: "kg" }

2. Aturan Ambang Batas Status Stok (Threshold Rules)

Penentuan status dilakukan secara real-time berdasarkan angka pada attribute stok:

  • Stok Habis Stok = 0: Bahan baku benar-benar kosong di gudang dapur. Harus segera di-order agar menu terkait tidak *off-menu*.
  • Stok Menipis Stok 1 s/d 10: Menyentuh batas minimum persediaan (Re-order point). Memberikan peringatan dini bagi chef/purchasing.
  • Stok Aman Stok > 10: Kuantitas persediaan mencukupi untuk kelancaran operasional dapur harian.

3. Formula Perhitungan 4 Tile Ringkasan (Computed)

  • Total Bahan Baku: Total `length` array data bahan baku.
  • Stok Menipis + Habis: Jumlah item yang memiliki status `MENIPIS` (stok 1-10) atau `HABIS` (stok 0).
  • Jumlah Kategori: Hitungan `Set` unik dari attribute `kategori`.
  • Total Satuan Stok: Penjumlahan (`sum / reduce`) seluruh angka kuantitas stok bahan baku.

4. Fitur Tambahan

Aplikasi dilengkapi dengan penyimpanan `localStorage` otomatis. Ketika Anda menambah, mengedit, atau menghapus bahan baku, data akan tersimpan secara otomatis di peramban web Anda.
